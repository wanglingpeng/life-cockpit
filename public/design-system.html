tests/design-system.test.js 断言：components.css 里定义的每一个 c-* 类，都必须在本页的 class 属性里出现—— 新增组件不补样例，npm test 就红。删掉组件不删样例，同样红。
想看别的主题色或暗色下的样子：用顶栏的主题切换，本页会跟着变（组件只吃 var() 令牌）。
按钮 c-btn

空态 c-empty

分两种，别混用：行内空态用于列表某一行或表单字段下方，只回答「这里为什么空」， 一句话就够；块级空态用于卡片正文整块为空，要同时回答「这是什么空」和「怎么开始」， 所以有标题 + 描述两级。图标走 24×24 / stroke 2 / currentColor / aria-hidden 五件套，不要用 emoji。 .c-empty-action 的命中区已补到 44px；块级动作直接复用 .c-btn。

骨架屏 c-skel

只给高度和宽度，扫光与圆角由组件提供；1.4s 循环，prefers-reduced-motion 下由 theme/ 全局降级为静态。骨架的尺寸要贴合真实内容， 否则加载完会跳一下——那比不做骨架更难受。

标记片段
表单行 c-form-row

.c-form-row 是网格容器（标签在上、控件在下）， .c-field 包住真正的控件并统一 44px 高与焦点环。 控件本身不要加 style="height:…"——高度由组件定。
