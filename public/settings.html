企业微信：手机建个群（拉个小号即可）→ 群设置 → 群机器人 → 添加 → 复制 Webhook 地址
Bark（iPhone 最快）：App Store 装 Bark → 打开复制 URL → 选 Bark 通道粘贴
Server酱：微信扫码登录 sct.ftqq.com → 复制 SendKey
已有配置时留空表示不修改
推送文案末尾会附上这个地址，点开直达驾驶舱

地图 Key（腾讯位置服务）

该 Key 仅用于地点搜索 / 逆地理定位；地图底图为高德瓦片（免费，无需 Key），留空也能正常显示。
申请步骤
① 打开 腾讯位置服务 注册并登录
② 控制台 → 应用管理 → 我的应用 → 创建应用
③ 在该应用下「添加 Key」，勾选 WebServiceAPI 与 JavaScript API GL
④ 在 Key 设置里把本站地址（localhost / 服务器 IP / 你的域名）加入 域名白名单
⑤ 复制 Key 粘贴到上方并保存，之后在地图页即可搜索地点、按定位落点
安全提示：JavaScript API 的 Key 必须写在页面里供浏览器调用，因此务必配置域名白名单，否则可能被他人盗用额度。系统本身不会内置任何 Key。

数据管理

导出将下载包含全部业务数据的 JSON 备份文件（不含密码哈希）。导入会覆盖当前数据，导入前系统会自动生成本地时间戳备份兜底，请仍谨慎操作。
