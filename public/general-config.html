外部系统

开启后，第三方系统可使用下方 AppKey / AppSecret 调用本系统的开放接口，实现数据互通。

访问地址
外部系统访问本服务的接口根地址
AppKey
请求头 X-App-Key
AppSecret
请求头 X-App-Secret，请勿泄露给他人
接口说明
方法路径说明
GET/api/external/tasks查询事务列表，支持 ?keyword= 与 ?page=&pageSize=
POST/api/external/tasks新增一条事务
PUT/api/external/tasks/:id更新指定事务
DELETE/api/external/tasks/:id删除指定事务

日历订阅

把本系统的事务与纪念日同步到手机 / 电脑自带日历，无需打开本系统即可查看日程。

使用步骤
  1. 复制下方的订阅链接
  2. 打开系统日历（Windows 日历 / Apple 日历 / Google 日历）
  3. 选择「添加日历 → 通过 URL 订阅」并粘贴链接
  4. 保存后即可自动同步，更新频率由日历客户端决定
