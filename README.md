# 生活驾驶舱（life-cockpit）

一款**零依赖、本地私有部署**的个人/家庭生活管理工作台。把散落在待办、账本、保险、健康、人情、轨迹等处的琐碎信息收进一个驾驶舱：**今天该做什么、家里有什么、钱在哪里、我的健康与回忆**，一个入口全部掌控。

> 全程运行在你自己的一台设备上，不依赖任何第三方云服务（AI 能力除外），数据不出本机。

---

## 核心设计

- **零依赖运行**：仅用 Node.js 内置 `http` 模块 + 纯前端页面，无 npm 依赖、无数据库、无构建步骤，`node server.js` 即起。
- **本地优先**：所有数据落在一个 `data/db.json`，可整体备份/导入导出，天然可控、可迁移。
- **移动端优先**：手机浏览器直接使用，底部语音键"一句话记下来"直达录音。
- **安全加固**：登录口令 PBKDF2 加密、保险库 AES+密钥派生加密、管理员权限门禁、导出自动剥离第三方密钥。

## 功能一览（四大域）

**今天（Today）** —— 首页驾驶舱
- 待办 / 周期任务（按日、周、月、年自动滚动），首页一键勾选完成，逾期折叠
- 到期提醒统一引擎：任务、周期、纪念日、证件效期、健康复诊、贷款、随礼聚合推送
- 快捷记一笔（一句话同时落账本/纪念日/待办）
- 节假日/周末问候 + 工作类任务自动折叠

**家底（Assets）** —— 家庭档案与资产管理
- 家人档案（含证件/保单临期提醒）、健康档案（血压/体重 + 近 6 月趋势）
- 资产 / 负债 / 房贷 → **净资产仪表盘**（资产 − 房贷 − 其他负债）
- 保险库（主密码加密的密码/密档）、证件效期、纪念日
- AI 票据速记：拍票据照片 → AI 识别金额/商户自动入账

**钱（Money）** —— 记账与财务
- 手工记账（分类、多账本）、收入/支出统计
- 人情随礼账（含年度生日/事件临期提醒"该随多少"）
- 房贷月供计算并入月报
- 生活月报：月度收支、手记、净资产生成

**我（Me）** —— 记录与成长
- 随手记（支持置顶、AI 润色/总结）、足迹（轨迹按年归档）、位置打卡
- AI 会话助手（关联近 30 天健康复诊上下文）
- 日历订阅（ICS，含周期/效期/贷款事件）

## 快速开始

**要求**：Node.js ≥ 22（`Dockerfile` 用 `node:22-alpine`；回归套件用 `node --test`；
SQLite 后端额外需要 22.5+ 的 `node:sqlite`）。**零第三方依赖**，clone 下来直接
`node server.js` 即可，不需要 `npm install`。

**直接运行**
```bash
# Windows
start.bat          # 或：node server.js

# Linux / macOS
./start.sh                        # nohup 后台
./start.sh --pm2                  # 推荐：PM2 守护 + 开机自启
./start.sh stop                   # 停止
```

启动后浏览器访问：

```
http://localhost:15808
```

> 端口可用环境变量 `PORT` 修改，如 `PORT=8080 node server.js`。
> 默认仅监听本机 `127.0.0.1`（安全默认）；局域网访问请 `HOST=0.0.0.0 node server.js`，公网部署建议由 Nginx/宝塔 HTTPS 反代。

**Docker / 飞牛 fnOS**
```bash
docker-compose up -d --build      # 端口与数据持久化见 docker-compose.yml
```
- 数据持久化目录：`./data`（挂载到容器 `/app/data`）
- 已含健康检查与自动重启

**宝塔面板 / 飞牛 fnOS**：不需要单独文档——两者都直接跑上面的 Docker 编排。
宝塔在「Docker → 编排模板」里贴 `docker-compose.yml`；飞牛用「Docker → 项目」指向本目录。
数据目录映射到宿主机 `./data`，升级只需重建镜像，`data/` 不动。

## 首次登录与安全

- 内置管理员账号 `admin`，登录后**请立即在设置中修改密码**。
- 登录口令以 **PBKDF2-SHA256（60 万次迭代）** 存储，与保险库加密同强度。
- 敏感数据（保险库条目/设置密钥/AI 密钥）以 **AES-256-GCM（认证加密）** 落盘，兼容解密历史 AES-128-CBC 密文。
- 保险库（密码/密档）额外由**用户主密码经 PBKDF2 派生 AES 密钥**加密，主密码不落盘。
- 敏感配置（推送凭证、地图 Key、AI 密钥、存储凭证）在导出/备份时自动剥离；`data/` 目录不进入代码仓库。
- **登录失败限流**：按「用户名 + IP」计数，连续失败满 5 次起指数退避（1s→2s→4s…最长 15 分钟），成功即清零；全站写接口另有每 IP 每分钟 300 次上限。
- **安全响应头**：HSTS（仅 HTTPS 反代时下发）、CSP 阶段 1（`default-src 'self'` + 地图/天气白名单）默认开启；观察或回退：`CSP_REPORT_ONLY=1`（只报告不拦截）、`CSP_DISABLE=1`（关闭）。
- **上传件鉴权**：`/uploads/*`（证件/合同扫描件等敏感图片）必须登录后才能读取，缓存为 `private`。
- **仓库内不留任何口令**：`docs/` 下的一次性脚本一律从环境变量 `ADMIN_PWD` 读取，不要写回明文。

> ⚠️ **口令轮换提醒**：2026-10-16 之前，`docs/` 与 `artifacts/` 下 42 个已提交文件中写有明文管理员口令，
> 工作区已清理，但**它仍存在于 git 历史里**。若仓库曾推送到任何远端（Gitee/GitHub），
> 请务必在设置中改掉该口令，并按需用 `git filter-repo` 清理历史。

## 数据与备份

- 全部数据在 `data/db.json`，支持**整体导出 / 导入**（带 schema 白名单校验，含库结构版本号 `schemaVersion`）。
- **一键完整备份（ZIP）**：设置 → 数据管理 → 「完整备份」，下载 `db.json + .storage-key + uploads/ + SHA-256 校验清单` 的 zip，可离机保存；恢复时解压后把除 `backup-manifest.json` 外的**全部内容**放回 `data/` 目录即可。ZIP 含密钥锚点，请妥善保管：**漏掉 `.storage-key` 时，即使 `db.json` 完整恢复，库里的 `enc:` 密文（设置项密钥、对象存储凭据等）也永远解不开**，新实例会另生成一把锚点，且不会报错。这条恢复流程由 `tests/backup-restore.test.js` 起全新隔离实例真跑一遍（含漏密钥的负向演练），不是文档承诺；详见 `docs/ARCHITECTURE.md` §11.11。
- **单实例锁**：同一 `data/` 目录同时只允许一个实例运行（`data/.instance-lock`），防止两个进程互相覆盖 `db.json` 丢数据；确认无其他实例却提示冲突时，删除该锁文件即可。
- 可配置 **S3 / MinIO 对象存储**自动备份到云端。
- 建议：定期导出备份，或在设置中启用对象存储自动备份。

## 隐私声明

- 数据默认**只存储在你的设备**上，不会上传到任何第三方。**AI 功能默认处于「未配置」状态**：只有在你自行填写 API Key，或部署者显式设置 `LIFE_COCKPIT_AI_KEY` 环境变量后，才会在主动调用时把请求发往对应模型接口。
- **启用 AI 后，调用会随请求发送上下文数据**：本月账本汇总、今日事务、30 天内到期事项、家人姓名与生日、近 30 天复诊计划、最近手记标题。请确认能接受再启用；「设置 → AI」的总开关可随时关闭。视觉任务（票据识别）另需单独配置视觉模型。
- 本仓库（Gitee）仅存放代码，**不含你的个人数据与密钥**（`data/` 已通过 `.gitignore` 排除）。服务端内置 AI 能力只从环境变量注入，源码里不放任何真实 Key；由 `tests/secrets.test.js` 做静态断言防回潮。

> ⚠️ **历史密钥**：本次修复之前，`src/services/ai.js` 曾写入一枚真实 API Key 且已进入 git 历史。升级后请到服务商控制台**作废/轮换该密钥**——删掉源码不等于撤销泄露。彻底清除历史记录需要重写 git 历史（不可逆），须单独授权后操作。

## 运维与安全速查（交付版 v1.48.54）

完整的部署、停服、备份、存储后端与安全模型说明见 **[OPERATIONS.md](./OPERATIONS.md)**。要点：

- **零依赖**：Node.js ≥ 22，拷贝目录即运行，无需 `npm install`。
- **优雅停服**：用 `stop-service.bat` 或 `POST /__lc_shutdown`（loopback + `X-LC-Stop-Token`），**禁止 `taskkill /f`**（会跳过 200ms 防抖落盘丢数据）；退出码 `75` = 优雅停服。
- **备份真实**：SQLite 模式下每日备份含 `db.sqlite`(+wal+shm) 与 JSON 快照；导出 ZIP 同样带 `db.sqlite`。
- **管理员门禁**：路由的 `auth/role:admin` 由 `handleApi` 统一校验，普通用户越权一律 `403`。
- **最小暴露**：静态资源仅白名单扩展名可匿名访问；`.bak/.json` 等不匿名下载；Service Worker 不缓存私有路径；微信登录默认走真实校验（仅 `MOCK_WECHAT=1` 模拟）。
- **交付前自检**：`npm test`（回归）、`npm run check`（测试 + 架构闸门）、`npm run arch:deps`（零外部依赖校验）。
